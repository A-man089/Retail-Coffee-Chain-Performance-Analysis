# Retail-Coffee-Chain-Performance-Analysis

# ☕ Coffee Shop Sales & Operations Dashboard (Power BI)

An interactive Power BI analytics dashboard built to monitor total revenue, order volume, product category performance, store location sales, and hourly peak transaction trends for a multi-location coffee retail chain.

---

## 📊 Key Highlights & Metrics (May 2023 Data)
* **Total Revenue:** $157K (+31.8% vs Last Month)
* **Total Orders Processed:** 33,527 orders (+32.3% vs Last Month)
* **Total Units Sold:** 48,233 items (+32.3% vs Last Month)
* **Average Daily Sales:** $5,056/day

---

## 🛠️ Tech Stack & Skills Demonstrated
* **Tool:** Microsoft Power BI Desktop
* **Data Transformation:** Power Query (M) for data cleaning, column splitting, and date/time parsing
* **Data Modeling & Calculations:** DAX (Data Analysis Expressions) for Month-over-Month (MoM) growth calculations, conditional KPI indicators, and hourly heatmaps
* **Visualization:** Custom card visuals, trend line graphs, donut charts, horizontal bar charts, and matrix heatmaps

---

## 🔍 Key Business Insights Included

1. **Location Performance:** Hell's Kitchen ($52.60k), Astoria ($52.43k), and Lower Manhattan ($51.70k) display balanced revenue distribution, with all store locations showing >30% MoM growth.
2. **Day-Type Distribution:** Weekdays account for **74.41% ($117K)** of total sales compared to **25.59% ($40K)** on Weekends.
3. **Product Categories:** Coffee ($60.36k) and Tea ($44.54k) drive over 66% of total revenue, followed by Bakery items ($18.57k).
4. **Hourly Peak Analysis:** Peak operating hours occur between **8:00 AM – 10:00 AM**, generating $19K–$20K across weekdays.
